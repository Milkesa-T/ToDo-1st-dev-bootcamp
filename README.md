## ✨ Features

- ➕ **Add Tasks** — Quickly add new tasks with a single click
- ✏️ **Edit Tasks** — Modify any existing task on the fly
- 🗑️ **Delete Tasks** — Remove tasks you no longer need
- ✔️ **Mark Complete** — Toggle tasks as completed with a checkbox
- 📊 **Live Stats** — Real-time counters for Active, Completed, and Total tasks
- 💾 **Persistent Storage** — Tasks are saved to `localStorage` so they survive page refreshes
- 🎨 **Modern UI** — Clean design with smooth hover animations and Lucide icons

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| **HTML5** | Page structure & semantics |
| **CSS3** | Styling, layout & animations |
| **Vanilla JavaScript** | App logic & DOM manipulation |
| **Lucide Icons** | Edit & delete icon set |
| **localStorage** | Client-side data persistence |

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/YOUR_USERNAME/todo-list.git
   ```

2. **Open the app**
   ```
   Open todo.html in your browser
   ```

That's it — no build tools, no dependencies, no setup required!
